# SDG Railway – quotation service (Apps Script v8)

The website (GitHub Pages) shows the forms and pages. This Apps Script project, attached to the
SDG Railway Google Sheet, is the back end:

- **Reads** the master data from the Sheet: terminals, links, services, timetables, tariffs,
  surcharges, Play Haulier road legs and teams.
- **Calculates** with `Engine.gs`, the same engine the website runs. It is generated from
  `src/engine` and checked against the 100 most recent v7 quotes, which match to the cent.
- **Records** every operation:
  - `QUOTE_LOG`: one row per quote version.
  - `BOOKINGS`: one row per accepted quote.
  - `HISTORY`: one row per action.
  - Drive: one PDF per quote, in the existing folder.
- **Numbers** quotes under a lock, so two teams quoting at the same time never get the same
  reference. Numbering continues the v7 series (`RWQ00000196`, …); bookings use `RWB00000001`.

Data is edited **only in the Sheet**. Changes reach the website within about one minute (cache).
To clear the cache at once: **Railway Quoter → Clear server cache**.

## Files (`apps-script/dist`, generated by `npm run build:apps-script`)

| File              | What it is                                                                     |
| ----------------- | ------------------------------------------------------------------------------ |
| `Code.gs`         | Web app API (`doGet`/`doPost`), reading and writing the Sheet, PDF             |
| `Setup.gs`        | **Railway Quoter → Set up v8** menu item: adds tabs and columns, never deletes |
| `Engine.gs`       | Routes, prices and trains. Generated: do not edit in Apps Script               |
| `Seed.gs`         | Initial rows for the new tabs. Generated from `apps-script/seed/v8-seed.json`  |
| `QuotePdf.html`   | PDF template                                                                   |
| `appsscript.json` | Manifest: Madrid time zone, web app runs as the owner and is open to anyone    |

The v7 files `Index.html`, `app.js.html`, `styles.css.html` and `Schedulesystem.gs` are not
needed: the website does their job, and the engine includes the timetable rules.

## Setting it up (once, about 15 minutes)

Do it with the account that **owns** the Sheet and the PDF folder.

1. **Copy the Sheet.** In Drive: right-click on `Railway_Quotation_System_v7_FIXED(Nombre)_Servicio`
   → **Make a copy**, for example _Railway_Quotation_System_v8_. The current v7 keeps working
   for your classes until you switch.
2. **Open the copy's script.** In the copy: **Extensions → Apps Script**. The project is a copy
   of the v7 code.
3. **Replace the code.**
   - Delete `Index.html`, `app.js.html`, `styles.css.html` and `Schedulesystem.gs`.
   - Replace the content of `Code.gs` and `QuotePdf.html` with the files in `apps-script/dist`.
   - Create the script files `Engine`, `Seed` and `Setup` (**+ → Script**) and paste
     `Engine.gs`, `Seed.gs` and `Setup.gs` into them.
   - In **Project Settings**, tick _Show "appsscript.json"_ and paste `appsscript.json`.
   - Save.
4. **Prepare the Sheet.** Reload the Sheet: the **Railway Quoter** menu appears. Run **Set up v8**
   and accept the permissions. It adds:
   - The tabs `ROAD_LEGS`, `TEAMS`, `BOOKINGS` and `HISTORY`.
   - The columns `SlotsPerDeparture`, `MaxGrossKg`, `VolumeM3` and the new `QUOTE_LOG`
     columns.
   - The new `CONFIG` parameters.
   - `SurchargeCode` in cell A1 of `SURCHARGES`, which was empty.

   It never deletes or changes existing rows.

5. **Teams.** In `TEAMS`, replace the example rows with your teams: one row per team, with a
   4-digit PIN. Rows with `Role` set to `trainer` see every team. **Change the trainer PIN 9000.**
6. **Publish the web app.** In Apps Script: **Deploy → New deployment → Web app**, with
   _Execute as: Me_ and _Who has access: Anyone_. Copy the URL, which ends in `/exec`.
7. **Connect the website.** In GitHub, open `portvirtuallab/sdg-railway-website` → **Settings →
   Secrets and variables → Actions → Variables → New repository variable**. Add the name
   `QUOTE_API_URL` with the `/exec` URL as its value.
8. **Publish the website.** Run **Actions → Deploy preview to GitHub Pages → Run workflow**
   (`main`).

If you change the code later (a new `Engine.gs`), use **Deploy → Manage deployments → Edit →
New version** so the URL stays the same.

## Checking that it works

- `<URL>?action=health` answers `{"ok":true,"version":"v8"}`.
- `<URL>?action=catalogue` returns the public tabs. It never includes `TEAMS`, `PdfFolderId` or
  the logs.
- Make the worked example on the website with a team's PIN. Then check:
  - A new `ISSUED` row in `QUOTE_LOG`.
  - A new PDF in the folder.
  - A `QUOTE` row in `HISTORY`.
- Accept the quote. Then check:
  - A new row in `BOOKINGS`.
  - The `QUOTE_LOG` row now `ACCEPTED`, with the booking reference.

## What each tab does

| Tab                   | Who edits it                      | Use                                                                |
| --------------------- | --------------------------------- | ------------------------------------------------------------------ |
| `CONFIG`              | Trainer                           | Currency, insurance, validity, cut-off, prefixes, default capacity |
| `COUNTRIES`           | Trainer                           | `Status = Active` countries appear in the forms                    |
| `TERMINALS`           | Trainer                           | Terminals (DG = handles dangerous goods)                           |
| `COUNTRY_CONNECTIONS` | Trainer                           | Which borders the rail network may cross                           |
| `LINKS`               | Trainer                           | Rail links: **adding a row adds a route**                          |
| `SERVICES`            | Trainer                           | Rail services (Standard, Express, Economy…)                        |
| `SCHEDULES`           | Trainer                           | Days, time, blocked dates and units per departure                  |
| `UTI_TYPES`           | Trainer                           | Loading units, with optional maximum load and volume               |
| `ADR_CLASSES`         | Trainer                           | Dangerous goods classes offered                                    |
| `TARIFFS`             | Trainer                           | Fixed fee + rate per km + minimum, per service and unit            |
| `SURCHARGES`          | Trainer                           | Surcharges with rules (`DG=YES`, `ORIGIN_COUNTRY=ES`, …)           |
| `ROAD_LEGS`           | Trainer                           | Play Haulier: door ↔ terminal, km, price, hours                    |
| `TEAMS`               | Trainer                           | PIN and name of each team; trainer role                            |
| `QUOTE_LOG`           | **Service** (do not edit by hand) | One row per quote version; the full quote is in `BreakdownJSON`    |
| `BOOKINGS`            | **Service**                       | Bookings, the train assigned and terminal orders                   |
| `HISTORY`             | **Service**                       | Who did what and when                                              |

The example rows the set-up adds to `ROAD_LEGS` (Toledo, Martorell, Corbas, Setúbal and Atessa)
and the values in `MaxGrossKg`/`VolumeM3` should be reviewed by the trainers.
