## Quotation feature (`src/features/quote/`)

| File                | Responsibility                                                                                                        |
| ------------------- | --------------------------------------------------------------------------------------------------------------------- |
| `types.ts`          | Request, quote, leg, line, train, booking types; Incoterms and RID classes                                            |
| `engine.ts`         | Pure functions: validation, lane resolution, single-source terminal charges, train search, quote building, acceptance |
| `handoff.ts`        | Click & Cargo handoff structure, `readyForErp` and blocking reason                                                    |
| `store.ts`          | Prototype persistence (browser) and reference sequences; replaced by the back end later                               |
| `QuoteForm.tsx`     | Step-by-step form, error summary, result and acceptance                                                               |
| `QuoteDocument.tsx` | Quote as shown on screen, in My quotes and in the printed PDF                                                         |
| `MyQuotes.tsx`      | Team view, detail, terminal orders, handoff                                                                           |
| `HomeSearch.tsx`    | Homepage search handing values to the form                                                                            |
| `time.ts`           | Deterministic date-time arithmetic (no time zones)                                                                    |
