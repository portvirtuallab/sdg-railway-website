# Acceptance criteria

From the brief (§4 table and §7), with the automated check that verifies each one.

- Unit tests: `tests/unit/quote-engine.test.ts` and `tests/unit/engine-parity.test.ts`.
- Back end on an in-memory Sheet: `tests/integration/apps-script.test.ts`.
- Browser tests: `tests/e2e/quote-journey.spec.ts` and `tests/e2e/pages.spec.ts`.

| #   | Criterion                                                                                                                        | Verified by                                                                                                                                                                                                                                      |
| --- | -------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| A1  | **RWQ and booking** are both visible, distinct, persistent and present in the PDF and export                                     | Integration: “runs the whole flow” (`QUOTE_LOG`, `BOOKINGS`, PDF content, `list`); e2e: worked example journey (status message, My quotes table, handoff download)                                                                               |
| A2  | **Train**: a verifiable departure, or a pending state that prevents continuation                                                 | Unit: “proposes the first Standard departure…”, “moves to the next departure when the proposed one is full”, “confirms the booking while there is room, otherwise leaves the train pending”; integration: “moves the next team to a later train” |
| A3  | **Price**: total equals the line items and the Sheet tariff, with no duplicate charges                                           | Unit: “adds the Play Haulier legs to the rail price of the Sheet” (sum of lines = total); parity: every logged v7 quote since 13 May 2026 matches to the cent                                                                                    |
| A4  | **Scope**: road legs and terminals marked included, excluded or pending                                                          | Unit: “excludes the road legs when the team uses the terminals”; the quote document shows a scope badge per leg                                                                                                                                  |
| A5  | **ERP**: the student can reproduce the operation without contradictory re-entry                                                  | Unit: “blocks the ERP handoff until the train is confirmed” (references, unit, route, train); handoff stored in `BOOKINGS.HandoffJSON`                                                                                                           |
| A6  | **Errors**: invalid PIN, uncovered route, unit limits, dangerous goods and unavailable train are explained without a false offer | Unit: validation and dangerous goods suites; integration: wrong PIN, other team's quote; e2e: “explains errors instead of producing a false offer”                                                                                               |
| A7  | The worked example (Toledo → Atessa, one 40 ft container) is priced from the Sheet by the same engine everywhere                 | Unit and e2e: €2,064.01 on Standard Rail; Teaching help computes it at build time                                                                                                                                                                |
| A8  | A quote is not a booking: acceptance creates the booking; superseded, accepted or expired quotes cannot be accepted              | Integration: accepting v1 after v2 and accepting twice are refused; the engine refuses quotes past `expiresAt`                                                                                                                                   |
| A9  | No duplicate references, even with simultaneous requests                                                                         | Back end numbers under `LockService`; integration: references continue the v7 series (`RWQ00000196`)                                                                                                                                             |
| A10 | Simulation notice on every page and on the PDF                                                                                   | e2e: every page shows the notice; `QuoteDocument` and `QuotePdf.html` carry their own                                                                                                                                                            |
| A11 | Accessible: keyboard, visible focus, labelled fields, announced errors, no serious axe violations (WCAG 2.2 AA)                  | e2e: axe on every page and on the quote result                                                                                                                                                                                                   |
| A12 | Every original page and URL still exists                                                                                         | Unit: “keeps all 13 source pages…”, “keeps every source URL path unchanged”                                                                                                                                                                      |
| A13 | Master data is edited only in the Sheet                                                                                          | The website has no copy of terminals, links, tariffs or teams; integration: “publishes the catalogue without private settings or teams”                                                                                                          |

## Manual checks on the Sheet copy

- Run **Set up v8** twice: the second run must say there is nothing to add.
- Make the worked example with a team PIN and compare the PDF in the Drive folder with the screen.
- Set `SlotsPerDeparture` to 1 for Standard Rail, accept a quote and request another for the same
  ready date: the second proposes a later departure.
- Add a link in `LINKS`, wait one minute (or **Clear server cache**) and check that the website
  routes through it.
